# 募集要項・学費表5列統一版（2026-10-28）

人間の「募集要項の方も同様の表に変えろ」に対応。写真入り新表紙のページ順、写真入り旧表紙の配布用A3/A4、文字のみ版のページ順/A3の現行5PDFを専用asset:get --savedで取得し、読順6P／印刷面6の学費表だけを修正した。

年次・時期／授業料／諸経費／施設設備費／合計の5列。施設設備費は各年50,000円を専用列の年額行に表示し、各期へ割り振らない。単独0と空欄記号はー（U+30FC）。入学金・年次合計・総額の行、数値、円の表記を保持。表の内部で列幅とセル余白だけを調整し、外枠位置・高さ・書体・配色を保持する。納期、返還規定、表紙、写真、願書寸法、白紙裏、QR、ページ数・面付け順は変更しない。旧PDFは別版として保持。

output/に修正PDFと配布ZIP、previews/に確認画像。入力実体はreceipts.json、元/新SHAと変更矩形はbuild-proof.json、全5PDF・84P/面の150dpi表外画素・ネイティブ文字/書体/字位置・全元画像stream一致と5列の数値検査はverification.json。登録はregistration.json、manifest.json。日本語名ファイル・取得証跡はdelivery-files.json。元の配布ZIPは募集要項2PDFだけ差し替え、パンフレット・チラシ・PRINTING.txtを同一バイトで保持。8PDFの日本語名ZIPも募集要項5PDFだけを更新し、直前のパンフレット3PDFを保持。

制作元はbooks/admissions-guide-2027/pages/page_007/page.htmlとpage.css。正本の数値・制度は変更しない。親が5表の拡大、写真入り/文字のみの料金ページと見開きを自己点検。独立審査・実物試し刷り・入稿承認は未実施。技術検査の未通過/実行中はchecks.jsonへ区別。保存とmainへのマージは別。
