# 無地版 R02：入試区分/一覧表の配色統一

人間がPDF4ページのAOだけ金色の分類帯、PDF5ページの日程一覧の意味のない色差を指摘。「色に意味と統一感を持たせる」「現状から大きく変えない」と指定した。

`color-policy.json` を今回と今後の編集方針とする。紺を見出し・分類の基本色、表の本文は白地と濃い文字、該当なしはグレー。金は章番号・共通の節目などのアクセントとし、AOだけの特別扱いには使わない。

4ページの3分類帯を紺＋白文字へ統一。5ページの3列の見出しを紺＋白文字、本文18セルを不透明な白＋濃い文字、左の項目名を白文字に統一。AO合格日だけの金背景を撤去。本文や日程の書き換え、文字サイズ・書体・位置、罫線・表構造の変更はしない。

既存PDFの演算子を読み、色/不透明度指定だけを挿入する。元の文字列/座標/描画命令のバイトは再組版・再直列化しない。検査は独立のPDF解析で文字/字形/位置、色の役割とコントラスト、画像ストリーム、全48面の変更領域外画素を照合。確認画像は新規プロセスでテキスト/画像抽出前に描画する。

```sh
python3 downloads/admissions-plain-20261025/r02-colors/build.py
python3 downloads/admissions-plain-20261025/r02-colors/verify.py
python3 downloads/admissions-plain-20261025/r02-colors/register.py
```

閲覧用は`output/admissions-plain-2027-r02.pdf`、A3/A4面付けは同名の`-A3.pdf`/`-A4.pdf`。各12面・6枚。願書記入にはA3・100%・短辺反転でA4仕上がり。A4面付けは縮小確認用。R01と写真入り原版は保持し、選択先ADM-JP-PLAIN-2027だけをR02へ更新する。

全体check/doctorは同じ作業ブランチの直前R01で実行済み。R01のvalidateは0エラー/205警告、全testは475成功/7既知失敗/7skip。今回はエンジン・facts・原版・テストに変更がないため重複実行せず、2ページの色変更に対応した個別検証と登録後のmetadata検査を行い、全量asset-integrityはGitHubの必須CIで確認する。直前の全体checkをR02の合格として扱わない。独立審査・実物試し刷り・入稿は未実施。
