## 再現・検証

`receipts.json` が専用asset CLI保存版取得の証拠、`baseline.json` が変更前の資料一覧と保護SHA。`render-panels.mjs` が正本から年額の料金表をベクターPDFとして描画し、`build.py` が元の各PDFの料金域だけを差し替える。合計数字は元のフォントを使い、元の字位置へ配置。印刷用で不足する数字は同じ制作元の閲覧PDFの同書体から取得する。

`verify.py` は新規プロセスでテキスト抽出前に全164P/面を150dpi描画し、料金域外の全面画素、文字・書体・位置、元の全画像ストリームを照合。不要になった透明画像も含め元オブジェクトを保持するため、画像の再圧縮・解像度低下はない。新料金・年額施設費の行数・旧料金残存なし・QR復号・願書の白紙裏面も検証する。検証対象SHAは `verification.json`。

既存Chromium154による確認用。独立審査・実物試し刷り・入稿承認は未実施。元の日本人版にあるICC警告は変更前後で共通であり、表示比較は一致。標準BOOKから全冊を再描画した最新版という意味ではなく、専用登録した保存済み料金改定版として取得する。mainへのマージは別指示で行う。
