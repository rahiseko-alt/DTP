# パンフレット・カリキュラム/資格変更の注記追加版（2026-10-28）

人間が承認した文言「※掲載しているカリキュラム・授業内容・目標とする資格・検定は、変更となる場合があります。」を、現行日本人向けR13のカリキュラム・目標資格の掲載ページ（PDF3/4/5/6/7/9）の下部へ追加。

資格紹介の4/6Pは既存の縦罫をまたがないよう左欄下部へ2行、9Pは学習サポート欄の縦罫より下へ配置した。文言は改行以外同じ。講師の取得済みGoogle資格を紹介する8Pは、学生の目標資格とは区別し、この注記を付けていない。学校概要・表紙・保護者・学費・入試/願書等への追加はない。

対象は現行日本人向けパンフレットのページ順・制作マスター・A3/A4中綴じの4PDF。それぞれ自分自身の現行PDFをasset:resolve/search/get --savedで取得して局所追加した。既存の本文・写真・表紙・年額表と指定の検定料別注記・ふりがな無し・授業時間欄削除・QR・AI注記・ページ数/面付けは保持。元医専版・募集要項・チラシ案と現行チラシ・Driveファイルは変更していない。旧版は履歴として保持。
