# 日本人向けパンフレット・文面修正版（2026-10-28）

現行PAM-JP-ISEN・R13の閲覧用、制作マスター、A3/A4中綴じ印刷用の4PDFを別改訂として保存する。元医専版、募集要項、チラシ、元の配布ZIPは変更しない。

「すべてオンライン」の断定を「オンラインを積極的に導入」へ変更。保護者ページの不安を、授業についていけるか・通学継続・学びと将来の仕事・費用へ置換。他ページも日本語支援・多言語対応・在留手続き・日本での就職を前提とする表現から、学習・学校生活・進路相談へ変更した。国際ビジネスの学習内容、正式な学科名・出願資格、制度は変更していない。9Pの右端で欠けた説明文と頁番号を欄内へ収めた。

2〜11Pは原本が文字を含む画像。原本の画像streamは保持し、修正する文字領域だけコードによる色面とネイティブ文字で差し替えた。新たな画像生成や写真の再描画はない。patches.jsonが編集可能な文面・位置指定、render-overlays.mjsがHTML/フォント描画元、overlay-packet.pdfが全51パッチのベクトル部品、build.pyが各現行PDFへ局所適用する制作元。各出力は自分自身の直前PDFを入力としており、異なる表紙・写真の版を取り違えない。

verification.jsonに全4PDF・48P/面の検査。指定領域外150dpi画素、元のネイティブ全字/書体/字位置、全元画像stream、ページ寸法/回転を照合した。新しい文字の領域内収まり、DOMはみ出しなしも確認。12〜16Pは変更せず、承認済み年額表と「上記金額には検定料2万円は含みません。」、ふりがな無し、AI注記、QRを保持。元のPDF由来のICC警告が描画時に出るが、入力と同じ画像streamを保持しており本改訂の画像変更ではない。

親が変更9ページの拡大画像と全ページ/印刷面一覧を目視した。日本語OCRは補助確認で、判読の正本ではない。独立審査・実機試し刷り・入稿承認は未実施。Chromium154確認用出力であり、標準全冊再生成や入稿保証と区別する。

取得元とSHAはreceipts.json、変更領域と出力SHAはbuild-proof.json、管理登録はregistration.json/manifest.json、提供名と保存済み取得証跡はdelivery-files.json。旧版は履歴として保持。mainへのマージは今回実施しない。全体チェックとGitHub必須チェックの状態はchecks.jsonを参照。
