# 資料の呼び方

制作・受け渡しの名前とタグは [latest-materials.json](latest-materials.json) に集約する。学校の事実は company-data の正本を参照する。

| 短い呼び名 | 固定ID | 現行の実体 |
| --- | --- | --- |
| 医専パンフ | PAM-ISEN-2028 | 医専白版・2028表記・16ページ |
| 日本人向け募集要項 | ADM-JP-2027 | 2027年度・24ページ・願書付き |
| 黄色OCチラシ | FLY-OC-YELLOW | 黄色いOPEN CAMPUS帯・2ページ・年度未確認 |

「現行」は現在の採用データを指す。「日本人版完成」「入稿可」を意味しない。3資料とも人物画像は日本人イメージに未統一。制作予定の日本人版は別の作業IDで扱い、完成ファイルがない間は `file: null` とする。

| 制作作業ID | これから作る版 |
| --- | --- |
| PAM-JP-ISEN | 医専パンフの日本人向け版 |
| ADM-JP-2027-PEOPLE | 日本人向け募集要項の人物差し替え版 |
| FLY-JP-OC-YELLOW | 黄色OCチラシの日本人向け版 |

## タグ

`種別:`、`意匠:`、`対象:`、`適用年度:`／`表記年度:`、`状態:`、`人物:`／`人物仕様:`、`用途:` を別々に記録する。「日本人向け」は募集対象、「日本人イメージ」は制作する画像の仕様であり、実写真の人物の国籍を外見から判定するタグではない。生成人物は在校生写真と区別する。

```sh
python3 system/scripts/list-materials.py --tag '状態:現行'
python3 system/scripts/list-materials.py --id FLY-OC-YELLOW
python3 system/scripts/list-materials.py --tag '状態:未制作'
```

資料実体は表示された `document` と `asset_id` で `asset:resolve → asset:search → asset:get` を使って取得する。制作予定を現行PDFで代用しない。検索結果がなければ停止する。

## 名前と印刷のルール

表示名は `種別_対象または意匠_年度_ページ数_状態`。配布する新ファイル名にはさらに `用途_用紙_改訂番号` を付ける。例：`募集要項_日本人向け_2027年度_24P_確認用_中綴じ_A3_r01.pdf`。改訂番号は実際に生成した時だけ進める。

本文の読む順のPDFと製本用の面付けPDFを分ける。中綴じA3は折ってA4、中綴じA4は折ってA5、どちらも横・短辺反転。パンフは4枚、募集要項は6枚。チラシはA4縦1枚・長辺反転。PDF閲覧アプリ側の「小冊子」機能を面付け済みPDFへ重ねて使わない。

既存の `print-pdfs.zip` 内の英語ファイル名は互換のため保持する。収録内容は latest-materials.json の現行3資料であり、未制作の日本人版を収録したとは扱わない。

## 取り違えを防ぐ

- アバター体験OCは別案。黄色OCチラシの代わりに出さない。
- HAL風パンフは別案。医専パンフの代わりに出さない。
- 実写真再構成OCの誤成果物は削除済み。再生成して採用版として出さない。
- 「白版20P」は原本の旧ページ数。現在のパンフは16ページ。募集要項の旧16ページとも区別する。
- パンフは2028表記だが学費・入試の根拠は2027年度。募集要項は2027年度。年度を統一したと見せかけない。
- チラシの開催年は未確認。「2028版」などと推測で命名しない。
- 内部のBOOK ID、アセットID、SHA、原本のファイル名は保存済み実体の識別子として保持する。`latest` だけで選ばず、資料ID・版・SHAと用途を確認する。
