## 点検と再現

取得は専用asset CLIの保存版経路。元版と表紙のSHA・取得証拠は `receipts.json` / `manifest.json`。`build.py` が新表紙を挿入してA3面付けを生成し、`verify.py` が全60P/面を150dpiで比較する。表紙以外の全面画素・ネイティブ文字・書体・字形・位置・画像ストリーム一致、A3全12面の左右順、2冊のQR復号、旧保管ファイルのSHA不変を確認。先頭印刷面は表紙以外の左半面も一致。

親が表紙、両版の全ページ・全見開き、印刷全12面を保存画像で目視。表紙の下線削除、本文の維持、裏表紙の保持、文字欠け/重なりと面付けを確認。点検対象PDFのSHAは `verification.json` に固定。独立審査・実物試し刷りは未実施。
