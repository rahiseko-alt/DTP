## 到達点

原画の構成意図を保ち、確定した学校情報と実際の学生写真で、冊子の各ページを組み替えられる制作基盤を作る。運用時に選ぶのは「仲間の多さを主訴求する見開きを入れるか」「冊子全体をどのデザイン体系にするか」「ページごとに実写真と明示的なデジタル表現のどちらを使うか」。これらを独立して選べるようにする。ページ内容を組合せ数だけ複製しない。

この計画は実行順・担当・成果物・合格条件までを確定する。ページ割、表現、学校情報、写真トリムの上位判断と、学校・印刷会社からの確認資料が揃うまでは、本番ページを生成しない。

## 固定する設計

### 運用軸

| 軸 | 選択肢 | 運用規則 |
|---|---|---|
| 任意コンテンツ | 外国人の仲間を主訴求する見開き OFF / ON | 2ページを一体で足すか引く。片面だけの追加は禁止。 |
| 全冊デザイン体系 | HAL系 / 医療・専門校系 | 表紙、見出し、本文、カード、表、写真処理、余白、ページ番号まで一式を切り替える。現在の `hal` / `isen` 部品差分だけを「全冊スタイル切替」と見なさない。 |
| 画像表現 | 実学校写真 / デジタルイメージ | ページ単位で指定。実写真は原画像を直接配置し、AIへ入力・人物改変しない。デジタル画像は現実の校舎・授業と誤認されない造形にし、紙面内に「イメージ」等の表示を置く。 |

組合せごとに冊子データを複製しない。単一コンテンツに版マニフェストと完全なスタイルプロファイルを適用して、指定された版を出力する。画像表現は全ページ一律ではなくページごとに指定できるため、全ページ組合せ（2^N）を定型版として保守しない。実装検査では「spread OFF/ON × style HAL/医療系 × 全ページ実写真/全ページデジタル」の8つを直交性の基本ケースとして通し、さらに実写真とデジタルが混在する1版を検査する。実運用のデジタル箇所はページごとのmanifest指定に従う。

### 忠実性・事実・素材のルール

- 近100%再現の基準は、原画の主従、写真と文字の比率、情報群、読順、密度、色の役割。学校の正確な情報へ合わせる必要がある箇所だけ変更理由と出典をページ別に記録する。承認なしの短文化、余白拡大、装飾追加、レイアウト再解釈をしない。
- 原画と生成済み参考素材は保存し、紙の遠近・影・綴じ目を含む冊子写真を印刷面へ貼らない。納品ページは平面で、文字は編集可能なHTML/CSS、図形は構造化要素、写真は独立素材とする。
- 既存の実写真79点は `company-data/photos/photos.yaml` を正本とし、複製・再登録しない。写真のSHA、出典、人物・第三者・画面・資料の使用条件を保持。顔から国籍、役割、母語、友人関係を推定しない。
- 学生数が多いことを見せる構成でも、日本人学生は現在0人という申告を守り、日本人学生や日本人の友人を足さない。友人獲得、交流実績、支援実績を写真から約束しない。公園を校庭と見せない。
- 不明な事実は空欄のまま「要確認」とする。2027年度の根拠を2028年度へ読み替えない。未確認の主張を真偽どちらにも断定しない。
