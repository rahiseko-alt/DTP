# 自分主演アバターMV体験：10人OCの運営設計案

作成日：2026-10-15（日本時間）。設計案であり、学校の開催決定・実績ではない。技術・費用・利用規約の選定は別担当。**実施可能性は未検証。2時間以内の全員完成は保証しない。**

## 体験のゴール

「自分の分身が空を飛ぶなど普段できないことをし、自分で録った声と音楽が付いた10〜20秒の動画」を作る。本人が選び、結果を確かめ、修正する。MP4を本人のスマホで再生し、帰宅後に家族へ見せられる状態を目指す。2D・リアルの選択肢はツール検証後に決める。初回は1形式に絞る方が運営しやすい。

話題のAIを講師が見せるだけでなく、本人が「分身・動作・せりふ・音楽」を決める。完成動画に加えて元のアバター画像と簡単な制作メモを渡す。音声はまず本人による短い録音を使用し、声の複製は必須にしない。録音が映像と一緒に聞こえることと、分身の口が同期することは別工程であり、口パク同期は標準要件にしない。

## 事前に整えること

- 参加申込時に、制作内容、外部AIサービスへ送る素材、利用目的、保存先・削除時期、未成年の扱い、素材提供を断っても参加できる代替方法を説明する。本人の制作利用への同意と、学校広報への掲載許可は別。初回は広報掲載を前提にしない。
- 当日本人が任意で撮影・提供する写真と声のみを扱う。既存の学校実写真、他の学生の写真・声、パンフレット人物画像をAIへ投入しない。本人写真を使わない選択では、本人が特徴を選んだ2D分身と本人録音で参加できる設計を検証する。
- アカウント共用可否、年齢・保護者同意条件、生成物の共有条件、提供素材の学習利用設定、削除方法を選定担当が確認してから募集する。学校が支払い、スタッフが操作してもサービス規約の年齢条件等を回避できるとは扱わない。ログイン情報を参加者へ配らない。
- 参加番号01〜10で素材と生成ジョブを管理し、顔・声を名簿と一緒に公開保存しない。他人の写真・完成動画が一覧表示されない受渡し方法を準備する。公開QRや期限なし共有リンクを使わない。
- 作品の受渡しと削除の期限は事前に実装確認し、参加者へ明示する。未定のまま「後日いつでも見られる」と案内しない。後日送付は本人・保護者が選んだ連絡先への個別送付とし、送付の実行は別途学校運営側が担当する。

## 必要設備とスタッフ（提案）

10人にPC10台、予備PC1台、講師投影用PC1台。本人スマホは持帰り確認に使い、持参・通信契約を参加必須条件にしない。スマホなしの場合は本人専用の受渡し先や持参媒体等を事前相談し、学校が対応可能な方法を決める。写真撮影用端末、静かな録音場所2か所、ヘッドセット、充電器を用意する。録音は全員が同じ教室で同時に始めない。

推奨は4人：進行講師1、巡回支援2（各5人）、生成キュー・受渡し管理1。受付終了後は受付担当を巡回へ回せる。入試相談を同時に別室開催するなら別に学校説明担当が必要。3人運営は事前素材受取・入力テンプレート固定などによる負荷削減を試してから判断する。未確定の在校生スタッフ配置を実績として告知しない。

## 120分標準案：生成待ちを学校説明と並行させる

受付は開始20分前から。開始時刻に全員の素材が揃う前提にはしない。各段階は時計だけでなく後述の進行判断を使う。

| 経過 | 本人がすること | スタッフの仕事・生成待ちの使い方 |
| --- | --- | --- |
| 開始前20〜0分 | 受付、同意確認、席へ。写真任意撮影、5秒程度のひと言録音、保存先確認 | 参加番号付与、素材の本人確認、他人映り込み確認。写真・録音を望まない場合の選択肢へ案内 |
| 0〜8分 | 完成見本を見て、分身・動作・ひと言・音楽の雰囲気を選ぶ | 完成物と本日の限界、素材取扱いを短く説明。長いツール講義はしない |
| 8〜25分 | 自分の分身を作り、候補から1枚選ぶ | 第1段階：アバター生成。遅い席は録音や動作選択を先行。再生成は原則1回までを運用案として試す |
| 25〜40分 | 「空を飛ぶ」等の動作と場面を指定、短い動画生成を開始 | 第2段階：動画生成。10人の同時投入が可能か事前検証し、必要なら5人ずつ時間差投入 |
| 40〜55分 | 学校・2学科紹介。自分が入力した指示と生成結果を比較する | 動画生成待ちを利用。国際ビジネスAI科のAI活用、総合ビジネス科の「誰に何を伝えるか」へ接続。これは当日の説明企画で、正式な授業科目の追加ではない |
| 55〜70分 | 動画を確認。音楽の雰囲気を選び、本人録音を確認 | 第3段階：音楽生成・映像と声の組合せ。音楽は早い段階に並行生成する運用もパイロットで比較 |
| 70〜90分 | 声・音楽の音量を調整し、MP4へ書き出す | 編集テンプレートを使用。台詞が聞こえるか確認。再生成の締切を75分とし、以降は完成優先の案を試す |
| 90〜105分 | 入試・学費の説明を聞く | 書出し・受渡し処理を並行。2028年度の未確定費用・日程・AO条件を確定扱いしない。参考年度の説明は年度を明記し、2028条件は確認後の案内とする |
| 105〜115分 | 自分の端末で再生。家族に見せたい点を一言でまとめる | 受渡し後に端末再生・音ありを個別確認。希望者のみ作品共有。他人の作品を無断で投影しない |
| 115〜120分 | 次の相談方法を確認して終了 | 未完成者の現状と個別の受渡し方法・期限を確認。残る質問は個別相談へ |

相談を希望する人は終了後に対応する。120分枠に全員の個別相談完了まで含めない。保護者が同伴した場合、制作中は見学または希望者向け相談とし、最後の本人作品再生に合流できるようにする。

## 進行判断と失敗対応

- 25分時点で分身未完成：候補の作り直しを止め、本人が選んだ1枚で動画へ。生成不良なら任意提供した本人画像の静止画アニメーション等へ切り替え可能か、別途事前検証する。
- 55分時点で動画生成未着手・失敗が集中：全員または該当席を短尺簡略案へ。無制限の再実行はせず、キュー管理者が状況を説明する。
- 75分を新規生成の締切候補とし、既にある素材で編集・書出しへ。生成が遅いまま「あと少し」と延長を繰り返さない。生成中素材を取り消せるか・費用が戻るかはサービスごとに確認する。
- 105分時点で未完成：アバター静止画、本人録音、途中プレビュー等の完成済み部分を本人へ渡す。本人主演動画の完成とは区別する。学校側で後日仕上げる体制がある場合のみ、本人の希望と送付期限を個別確認する。当日完成保証は募集時点でしない。
- 音声不良：短く録り直し。声の複製を即興導入しない。音楽ができない場合は利用条件確認済みの学校用BGMへ切替え、音楽生成は未体験だったと説明する。
- 操作が苦手：短文の選択シート、入力見本、スタッフの代行入力で支援。本人に選んでもらい結果を比較する部分は残す。早い人には別パターンの指示文作成を勧め、生成回数を増やしすぎない。
- 遅刻：15分以内は支援員が要点説明し同じ工程へ。以後は簡略案を優先。受付可能な締切は試行後に定め、予約時に案内する。遅刻者を講師が都度最初から説明して全体を止めない。
- 欠席：素材を事前受取していても本人不在で生成しない。規定の期限で素材を削除。欠席者の参加枠を別人へ振り替える際、他人の素材を引き継がない。

## 短尺簡略案（技術検証が難しい場合の初回候補）

本人の分身1枚＋非日常動作1カット（5〜8秒）＋本人録音1文＋生成音楽1曲の短い部分。編集テンプレートでタイトル・音量・終端のみ調整し、合計8〜12秒程度の動画にする。シーンの連続性、口パク、声の複製、歌声生成、複数カットは求めない。本人の分身・本人の声・非日常動作の三つは残す。

アバター生成15分、動画投入10分、待機と学校紹介20分、編集20分、受渡し15分を仮の制作進行枠とし、残りを導入・入試説明・バッファに配分する。これも時間保証ではない。動画生成そのものが使えない場合の「静止画＋動き＋本人声」は別の代替体験と説明し、空を飛ぶ動画ができたと称さない。

## 家族へ見せる内容

スマホで動画を再生し「この分身が自分」「この声も自分」「動きと音楽をAIで作った」と説明できる状態にする。制作メモには本人が決めたこと、使った道具、直した点を3行程度で残す。学校紹介への接続は「選ぶ→指示する→結果を確かめる→伝わる形に仕上げる」であり、参加1回で専門技能が身についたと誇張しない。家族宛てメッセージ録音は任意にする。

## 募集前パイロットの合格判断

まずスタッフ2人分を連続実施し、次に実利用条件で10人分を同時処理する。学校ネットワークと当日PCで行う。平均時間だけでなく最遅値を記録する。

1. 写真・録音受取時間、本人確認、拒否選択を含む受付滞留。
2. 各段階の投入・待ち・完成時刻、同時実行制限、生成失敗・再試行回数、誰の素材か取り違えない管理。
3. 顔の再現性、非日常動作の崩れ、録音明瞭度、音量、書出し時間。表現の違和感を本人が許容できるか。
4. 初心者の操作時間、支援員が一人に拘束される時間、4人配置で10席を支援できるか。
5. スマホのOS別の受取・再生、スマホなし時の受渡し、共有リンクの本人限定・失効、サービス内素材とローカル素材の削除確認。
6. 使用量・実費、失敗時の費用、利用規約と年齢条件。これは別担当の料金調査と実測を突き合わせる。
7. 120分終了時の完成数と未完成理由。全員が完成するまで何分必要だったか。簡略案へ切り替える判断時刻が適切か。

結果に応じて、予約定員、所要時間、生成回数、後日受渡し可否、標準を短尺案にするかを決める。募集チラシへ「10〜20秒MVを当日必ず完成・持帰り」と掲載する前に検証を終える。
