# 本人の分身で、空を飛ぶ短いMVを作るOC

2026-10-15、ユーザーが『一旦avatar案で進めろ』と指示した**採用企画**。本人に似た2D/リアルの分身、空を飛ぶ等の非日常動作、本人声、生成音楽を組み合わせ、10〜20秒の短い動画を持ち帰る。写真を使わない一般アイコンの企画ではない。

以下の10名・2時間・価格・工程・使用サービス・参加条件は検証前の作業仮定。開催日、契約、学校の正式OC受付、AO条件は未確定。サービス購入・専用画面実装・実性能検証はまだ行っていない。破棄済みのチラシを再作成しない。

## 参加者が行うことと完成物

1. 自分の分身を2D/リアルから選び、衣装・雰囲気・場面を決める。
2. 任意参加の本人素材を当日新規に取得し、許可された方法で分身候補を作る。本人らしさを見て選び直す。
3. 『空を飛ぶ』『雲の上を歩く』等の動作とカメラを指示し、短いカットを生成する。
4. 本人が短いせりふやメッセージを録音する。声クローンをせず、録音を動画へ合成する。
5. 好みの音楽の方向を決め、生成BGMを選んで組み合わせる。
6. 10〜20秒に編集し、自分の端末へMP4を保存して再生確認する。

『本人声で歌う』『口の動きを声に同期する』は別難易度で未実証。今回の最小構成は本人の短い録音とBGMを重ねる。持帰り方法も実機pilotで確認してから告知する。

## 本人素材と既存写真を分離する

既存の学校実写真はAI入力禁止を維持し、在校生写真フォルダの写真を使わない。今回想定するのは、参加本人が任意に提供する**当日の新規素材**。本人の説明・同意と、必要な保護者同意、採用ツールの年齢/モデル条件を満たす方式に限る。一般的なアカウント年齢条件だけで未成年のリアル顔入力可とは判断しない。

本人写真を使えない/使いたくない場合は、本人が髪型・服・特徴を言葉で指定する2D分身へ変更する。顔写真不要の案はfallbackであって、ユーザーが採用した本人分身企画を一般アイコンに置き換えるものではない。素材の保管期間・削除手順・持帰り権・学校側再利用の有無は実施前に明文化する。

## 仮の2時間進行（10名）

| 経過 | 内容 |
| --- | --- |
| 0〜10分 | 学校/2学科紹介、今日作る動画の完成見本 |
| 10〜20分 | 素材の扱いと本人/保護者同意・ツール条件確認、分身/場面の企画 |
| 20〜35分 | 新規本人素材、分身候補生成・選定、本人声の録音 |
| 35〜65分 | 動作を指示し短い動画を生成。キュー待ち中に音楽とメッセージを準備 |
| 65〜85分 | 許容回数内で作り直し、カット結合・録音/BGM合成 |
| 85〜95分 | MP4保存・本人端末の再生確認 |
| 95〜105分 | ミニ上映、どう指示を変えたか共有、2学科の学びへ接続 |
| 105〜120分 | 入試/AOと費用の説明・本人/保護者相談。確定した年度の情報だけ使用 |

分身から保存までは約75分の仮割当。動画制作に最低60分程度必要という想定で、実測した必要時間ではない。10名の待ち行列やトラブルを含め2時間に収まるかpilotで検証し、体験時間・スタッフ人数・説明の配置を調整する。

## 学校管理の生成方式

学校管理API＋専用受付画面を優先案とする。参加者は指示と選択を行い、APIキーは学校サーバーだけに保管。会社のログイン・パスワード・APIキーを参加者へ共有しない。職員複数名が管理する場合も個別の正式ユーザー/権限を使う。

同時生成数はアカウントTierとモデルに依存するため、10名分を受付して順番処理する。待ち時間は分身選択・せりふ録音・音楽選定・指示の改善へ使う。学校専用UIは未実装、契約のend-user条件・表示・年齢制限への適合も未確認。

## 初期予算と生成上限

1人最大20秒×3試行×10名=最大600生成秒を初期予算にする。Runway Gen-4 Turbo公式$0.05/秒なら動画$30。1 USD=150円の仮換算で合計4,500円、1人450円。画像・生成音楽・税・編集/開発/スタッフ費は別。途中カットの作り直しも生成秒数へ計上する。

全員が20秒を1回余分に作り直すと200秒増え、同単価で$10追加。運用では上限表示と職員の追加承認を設ける案。月額WebcreditとAPIcreditは同一と仮定しない。比較・公式根拠は ../oc-ai-experiences-20261015/cost-research.md 。無料で10名の安定運用ができるとは見込まない。

## Pilotで必ず確かめること

- 2D/リアル双方で本人らしさを維持できるか。参照画像・生成分身・動画の段階で比較。
- 『空を飛ぶ』等の動作が不自然な崩れなく10〜20秒の作品になるか。複数カットの結合を含む。
- 対象年齢・同意・本人写真/声の入力条件を、採用モデルと契約で満たせるか。
- 録音を載せ、BGM音量を調整し、本人声が聞き取れるか。リップシンク不要で成立するか。
- BGMの生成・動画への組込・参加者への配布が契約上可能か。
- 10名分、最大600生成秒での実待ち時間・失敗率・料金・職員負荷。
- 自分の端末でMP4をダウンロード・再生できるか。参加者間で素材が見えないか。

## 失敗時のfallback

- リアル顔が不適合/本人らしさが崩れる：許可された2D分身へ。本人写真を使わず本人が特徴を言葉で指定する方式も用意。
- 動作生成が失敗/時間超過：成功した短い生成カット＋分身の静止画パン/ズームを組み合わせ、本人声と音楽で10〜20秒の作品にする。動画生成の成功を偽らない。
- 本人声のAI利用条件が合わない：録音そのままローカル合成。録音を希望しない場合は本人の文字メッセージ。
- 音楽ライセンス/生成が未解決：学校が配布可能と確認したBGMを代替として説明。生成音楽を使ったとは表示しない。
- 保存できない：本人専用の学校管理受取手段へ切替。後日受取が必要ならその場で明示し、当日持帰り成功としない。

fallbackを使った場合は当日の実施内容として区別する。企画の採用は、全サービス条件や持帰り成功を既に確認したことを意味しない。
