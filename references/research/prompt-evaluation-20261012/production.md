# 全候補評価：編集制作・デザイナー視点

編集制作・デザイナー視点。指示原文14ファイル（SHA同一をまとめると12本文）全件。人気指標不使用。技術README5件はユーザー指定により評価対象外。

## 推奨

今回の直接課題は空白を増減する一般論でなく、HAL参照の主従・密度・疎密を読み取って使える12ページへ編集すること。密度とリズムを現物証拠で検査するLayoutを制作の中心、Visual Storytellerを全体編集、Frontend Designを依頼照合と自己批評へ。役割を置換・原文改変はしていない。

Impeccable Bolder は既存面の表現強化、Impeccable Critique は独立審査、Image Prompt Engineer は部品制作の候補として別役割に残す。全体にそのまま適用する原文はない。原文の保存と評価は分け、勝手な改変や採用設定は行わない。
