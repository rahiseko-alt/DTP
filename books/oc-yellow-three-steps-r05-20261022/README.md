# OC黄色帯・裏面3ステップ R05

2026-10-22の人間の指示「裏面、在校生交流はなくして、3ステップにしろ」に対応。
読者・目的は確定台帳を維持。R04の表面と裏面の写真・地図・連絡先を保持し、当日の流れだけを「1 学校説明 → 2 体験授業 → 3 個別相談」に変更する。旧在校生交流の番号・見出し・人物アイコン・説明を除去し、3列に再配置。元の青い見出し・枠・ピンク番号・各説明とピクトグラムを引き継ぐ。新しい人物加工は行わない。

制作元は管理取得したR04 PDF（`reviews/source-get.json`）。`build.py` が固定PDFの指定範囲へコードで文字・構造を配置し、残る3アイコンだけを同PDFから再配置する。手動検索した別画像を素材として使わない。

```bash
python3 books/oc-yellow-three-steps-r05-20261022/build.py
python3 books/oc-yellow-three-steps-r05-20261022/verify.py
python3 books/oc-yellow-three-steps-r05-20261022/register-output.py
```

PDF内の未使用フォントだけをfontTools経由でサブセット化。写真の再圧縮・解像度低下は行わない。短い配布名は `downloads/oc-flyer-r05.pdf`。管理上は保存済み確認版であり、標準rendererからの現行入力再生成を保証した出力として登録しない。R04と原本を上書きしない。

`verify.py` は最終PDFのSHA、表面全画素、裏面流れ欄の外の全画素、ページ寸法、表裏のPNG/PDF計4QRを検査する。親が最終両面を画像で自己点検。独立審査・試し刷り・入稿確認は未実施。
