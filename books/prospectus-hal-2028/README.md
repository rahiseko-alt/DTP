クリスタル系のAIコアは3ページの背景透かしだけに使用。未来ゲート・銀枠・女性透かしは前景にも教材にも使わない。表紙の女性は保存済みの生成イメージで、実在校生・教員ではない。原本と生成記録はbackgrounds/へ保存。指定参考紙面の構図を参照し、他校の人物・作品・文字は転載しない。

使用写真ID：student-dsc-1164、student-img-5074、student-img-5073、student-img-5069、student-img-5238、student-dsc-1264、student-img-5235。写真は登録済みの在校生・一般課題・グループ活動。特定学科の実習と断定しない。5ページの街は説明用の単純図で、実学生作品や実生成結果として扱わない。

学費は2027年度日本人向け募集要項の参考金額。2028年度の確定学費・支払時期・日程・条件は学校へ確認する。支援・実績・学生の声は創作していない。
