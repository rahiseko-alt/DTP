- 2–3：学校の人から、国際ビジネスAI科の学びへ。登録済女性写真、授業風景、具体語と短文を複数のまとまりで編集。

## 初回制作での人間による停止（旧版の経緯）

余白・分かりやすさへの偏りを指摘され制作停止。この停止時点ではp1–3のみの初回方向版で、p4–5は未制作だった。旧版はreviews/trial-v1/へ保全し、採用済みとは扱わない。

## 再制作（役割候補v2）

人間の「再度作れ」により、余白・短文化・単純化を一律に優先する旧指示を解除した役割候補v2で再制作。代表2–3を3回方向確認し、編集長が人物脇の学科群・幅違い写真・巨大文字と作品の前後関係を承認してから4–5へ展開した。

1は女性と巨大AI、2–3は人物主導と作品説明主導、4–5は濃色の学科編集と白地の費用・相談を対比する。画像生成の景色は説明用イメージであり、学生作品ではない。写真ごとに具体内容を対応させ、AI授業や就職実績と誤認させない。出力はpreviewであり、正式入稿版・人間採用済みではない。最終PDF版に対応する独立レビューと編集長判断はreviews/へ保存する。
