# 医専日本人版（PAM-JP-ISEN）

2026-10-21の人間の指示による、医専16Pの写真差替版。HAL版ではない。制作元の医専版は上書きしていない。

- 表紙：指定された `shared/generated-assets/cover-group-jp/日本人版マシな方1.png` を等比配置。元の校名・大コピーの画素を維持。
- 大写真と学びの小写真：自然な日本人イメージの架空人物へのAI編集。男性のひげ、肌と首のつながりなどを点検。国籍を外見から断定したものではない。
- 講師面：人間採用済みR07を使用。人物画素を保持し、上と左の教室背景のみ生成で延長。
- 支援・保護者面・学費面の教室写真も編集。人物加工写真を実際の在校生・教職員を撮影した写真として表示しない。
- レイアウト、文章、料金・条件、校舎、地図、QRを維持。PDF順13〜16は原本と全面画素一致。

## 作り方と点検

この版は、元から紙面画像を埋め込んだ医専PDFに対する固定アダプター。写真の切出し・マスク編集・元文字画素の復元で更新し、ページ全体を画像生成し直していない。HTMLで全文を再組版した版ではない。元BOOKの標準描画対象4Pを16Pの代わりにしない。

`python3 books/prospectus-jp-isen-2028/build.py` で無劣化の16P PDF・確認画像・面付けPDFを作り、`python3 books/prospectus-jp-isen-2028/compress.py` で200dpi/JPEG92の閲覧・印刷用を作る。入力写真・生成記録・マスク・各担当の再現scriptは `work/`。管理済みPDFは制作元資料IDの別variant `japanese-people-edition`、別asset ID `jp-isen-*` に登録する。原本の `latest-prospectus-pdf` は変更しない。

確認用。表紙の指定画像は配置後の元情報量が約131dpiで、画素数の拡大は細部の増加を保証しない。入稿品質・実物印刷・人物同一性は未承認。パンフの2028表記、2027年度根拠の学費・入試は今回変更していない。

閲覧用は16P。印刷用A3/A4は各8印刷面・用紙4枚、横置き・両面短辺反転で中央を折って留める。面付け済みなのでプリンタの小冊子機能を重ねて使わない。
