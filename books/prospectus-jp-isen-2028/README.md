# 医専日本人版（PAM-JP-ISEN）

2026-10-21の人間の指示による、医専16Pの写真差替版。HAL版ではない。制作元の医専版は上書きしていない。

- 表紙：指定保存画像 `shared/generated-assets/cover-group-jp/日本人版マシな方1.png` の人物・壁・床・足元の影を保持。元医専の英字見出し・校名・白い明朝コピーを元位置へ置き、文字の下に足りない前景床だけ生成延長。本文は人間確認済みの改稿2を固定。
- 大写真と学びの小写真：自然な日本人イメージの架空人物へのAI編集。男性のひげ、肌と首のつながりなどを点検。国籍を外見から断定したものではない。
- 講師面：人間採用済みR07を使用。人物画素を保持し、上と左の教室背景のみ生成で延長。
- 支援・保護者面・学費面の教室写真も編集。人物加工写真を実際の在校生・教職員を撮影した写真として表示しない。
- 本文のレイアウト、文章、料金・条件、校舎、地図、QRを維持。PDF順13〜16は原本と全面画素一致。

## 作り方と点検

この版は、元から紙面画像を埋め込んだ医専PDFに対する固定アダプター。表紙は `work/revision9-cover/build_cover.py` で元医専の見出し・明朝コピーと、指定元画像の壁・床・足元の影を保持して合成。本文は写真の切出し・マスク編集・元文字画素の復元で更新し、ページ全体を画像生成し直していない。元BOOKの標準描画対象4Pを16Pの代わりにしない。

`python3 books/prospectus-jp-isen-2028/build.py` で無劣化の16P PDF・確認画像・面付けPDFを作り、`python3 books/prospectus-jp-isen-2028/compress.py` で200dpi/JPEG92の閲覧・印刷用を作る。入力写真・生成記録・マスク・各担当の再現scriptは `work/`。管理済みPDFは制作元資料IDの別variant `japanese-people-edition`、別asset ID `jp-isen-*` に登録する。原本の `latest-prospectus-pdf` は変更しない。

改稿2では表紙の写真下端・左端残片、本文の髪/首/襟の境界、服の変更、赤い文字片、吹き出しへの旧写真の食込み、壁看板と見出しの矩形を修正。詳細は `reviews/revision2-body-review.md` と `reviews/final-review.md`。

確認用。表紙の指定保存画像自体は生成素材。今回の人物/室内はその元画像を保持し、新生成物は前景床だけ。crop元幅1080pxをA4幅相当に配置し、人物写真の元情報量は約131dpi。画素数の拡大は細部の増加を保証しない。入稿品質・実物印刷・人物同一性は未承認。パンフの2028表記、2027年度根拠の学費・入試は今回変更していない。

閲覧用は16P。印刷用A3/A4は各8印刷面・用紙4枚、横置き・両面短辺反転で中央を折って留める。面付け済みなのでプリンタの小冊子機能を重ねて使わない。

改稿3は表紙のみ。`verify-cover-only.py` で確認済み改稿2のmaster/閲覧用PDFに対するP2〜16の全面画素・ネイティブ文字一致を検証する。写真・本文の再編集は行わない。

改稿4は表紙下部の背景を明るいグレー（#848B97）へ変更。人物・文字の輪郭/位置は維持し、元の暗い文字縁だけを新背景へなじませる。本文は引き続き確認済み版を固定。

改稿5は不透明な下部塗りを連続透過グラデーション（最大不透明度40%）へ変更。写真の下端を広いsmoothstepフェードでなじませ、元文字から白のαを取り出して旧背景の縁を除去。薄い文字影で可読性を補う。文字位置・人物素材・本文は固定。

改稿6は帯の上端を「AIを使いこなす」の文字上端（原寸y2779）へ下げた。最大不透明度40%と薄い境界フェードは維持。人物・文字位置・本文は固定。

改稿7は表紙写真の追加透過マスク/下端フェードを撤去。元の上半身切抜きが持つαだけで合成し、下端をそのまま表示する。丸い消え方を作らない。写真と文字/帯の位置、本文は固定。

改稿8は切り落とした写真の下側を既存の同じ透過素材から戻し、写真とコピー間の帯状の空白を撤去。写真上側と文字/帯の位置、倍率、本文を維持。丸いマスク/下端フェードなし。新しい脚の生成はしていない。

改稿9は切抜きをやめ、指定元画像「日本人版マシな方1」の教室・人物・接地影をそのまま使用。生成物はコピー下に延長した床の部分だけで、人物/教室全体は元画像を戻す。写真領域は配置後の元画像と全面画素一致。本文は固定。写真の元情報量は約131dpi。
