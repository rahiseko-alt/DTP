# 日本人向けパンフレットの構成方針

2026-10-21の人間の指示に基づく制作ブリーフ。医専ベースから離れ、HALの構成を参考に再構成する。今回は方針と参考の確認であり、紙面の再制作・PDF差替はまだ行わない。

## 人物の役割

学ぶ内容、制作するもの、活動をパンフレットの主題にする。人物は高校生が自分の学園生活をイメージするために使い、大人数の集合写真を表紙に使わない。大写真を一律に人物以外へ置き換えることは求めない。4人程度までの日本人らしい人物が写る授業・相談などの写真は使用できる。「日本人らしい」は制作上の外見イメージであり、実在人物の国籍の判定ではない。

参照画像を実際に開いて確認した。学科名、企業、人物、実績、学生作品、写真、ロゴ、固有コピーは転用しない。自社の確定事実を使い、生成した制作例は実在の学生作品・実績として扱わない。

## 次に組む代表面

1. 表紙：学ぶ内容・制作物と大きな見出しを軸に新構成を提案する。集合写真を差し替えながら使い続ける方針は終了。
2. 学科紹介の見開き1組：主役の作品・画面と、少人数の作業場面、具体的な説明の大小を組む。実際のカリキュラムは確定資料で確認する。
3. 講師ページ：採用済みR07写真は4人の授業場面。人物を使う目的がある候補として保持し、新しい全冊構成へ配置する際に再確認する。

まず表紙と代表見開きを目視して方向を確かめ、全冊へ展開する。ページ数・年度・学費の適用年度は、この方針転換だけで変更しない。
