## 証拠・再実行時の注意

[保存manifest](archive-manifest.json)は元/tmpパス、保存先、元ハッシュ/保存ハッシュを記録する。報告Markdownのリンクだけ相対化した。rawログ/スクリプトは当時の絶対パス・fixtureを含む観測証拠であり、そのまま再実行できる移植済み回帰試験ではない。再現は必要な分だけ/tmp独立コピーへ適合して行う。元repoへの反例注入・SIGKILL・権利撤回データ書込はしない。

/tmpの全clone、写真実体、コンタクトシート、描画cache、全生出力までは保管していない。保存対象はmanifest記載分のみ。画像の再確認は正本の写真ID/原本SHAから行う。79点を毎回個別読込せず絞り込み/コンタクトシートを使う。

今回の保存は文書変更。アプリコード・基準値・学校確定台帳・原本・写真の修正はない。マージはユーザーの明示指示が出るまで行わない。
