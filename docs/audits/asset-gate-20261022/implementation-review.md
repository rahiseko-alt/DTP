# 実装と目的条件の照合

GitHub必須asset-integrity・strict・保護は維持。検査を外して通す変更ではない。

- 保存版は専用archiveで実体/参照を検証し、通常get/search/build入力で拒否、--savedでのみ同定済み保存物として返す。参照先の欠損/不一致/循環/役割も確認する。
- 旧広域入力のSHAは現入力で更新しない。保存277実体と配布/表紙等36保護ファイルのSHAを維持。
- 正規baseline同期から出力鮮度だけを分離。内容不正・欠損・未確認・未登録・禁止語/権利等は維持。同期しても現行出力のSTALE拒否は残る。
- 今後の標準描画では設定/正本宣言/実参照shared/partial/CSS/font/描画コードの依存を採取し、描画前後と登録前で集合全体を再照合。取得時も集合を再採取する。
- current getterの外部入力はバイナリのままSHA照合。UTF-8文字列化して画像/fontを誤ってSTALEにしていた点も修正。
- supportも登録依存がある場合は鮮度検査の対象へ追加。日本人版の固定アダプター出力は保存版として正確に扱い、自動で最新描画保証へ昇格させない。

## 独立レビューと反例

当初目的/原因/変更案を3担当が検証。実装後に別担当が検査。引用符内の>、HTML/CSS文字列内のコメント記号により使用画像を取りこぼす反例を発見したため、HTMLはparse5、CSSはPostCSS/value parserへ変更。画像変更の検出がtrueとなることを同じ反例で再実行し、回帰試験も追加。別BOOKの依存証拠を接続する誤りも拒否する。

実Chromiumで標準BOOKを描画/登録/取得し、正規同期後の未使用候補追加は通り、実使用画像の変更はSTALE_OUTPUTで拒否した（live-render-proof.json）。実資料は再描画していない。既存PDF/画像とdocs/concept.mdは保全した。

## 保証の範囲

保存済み配布版は内容の同一性を保証し、現在入力で再描画した最新版であることまでは保証しない。したがってGoal2の『全資料の最新描画物を取得』を全面達成したとは報告しない。今後の正規再描画が新しい入力証拠を作る。保存状態から同じID/SHAを汎用再登録して状態だけを消すことはできない。

入力採取は宣言的な標準BOOK用。任意JS・未対応動的資産は安全側拒否。正本宣言と自BOOKソースは集合で監視する。ブラウザバイナリ/OS代替font/ロック外の任意node_modules改変はこの素材検査単独の保証外。別rootのengine/font/codeミラーが実際の実行環境と違う場合も拒否する。

入稿の見た目・事実の意味・初回資料同定の人間の間違いはasset検査の単独保証外。別途の原本照合・紙面目視・印刷確認が必要。

## クリーンなコミット環境の追加確認

初回CI（39710496574）は型検査/127試験成功、最後の検査で失敗。コミットのみの別worktreeで同じLEGACY_MISSING6件を再現した。未追跡かつGitignore済みのcache3・面付け中間PDF2・埋込HTML1がローカルの同期記録に混入していた。legacy比較/同期のみGitの未追跡ignored中間物を除外し、既存キーにも適用。trackedはignore規則でも保護、managed/registered検査は独立。サブが目的条件とこの範囲を独立確認し、tracked欠損とignored登録実体欠損の対の試験を追加した。保管済みとして案内する正式PDF/PNGは登録先・出力先とも追跡済み。
