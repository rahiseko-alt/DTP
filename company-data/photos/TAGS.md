# 写真タグの付け方

`photo:add` で新しく登録する写真には、検索で見つけやすいタグを2つ以上付けます。目安は3つで、「場面・活動・写っている対象」から選びます。

正規タグと日本語などの検索別名は [tags.yaml](tags.yaml) を管理元とします。新しいタグを追加するときは、既存写真の検索結果や意味の重複を確認し、この辞書へ正規タグと別名を登録します。`photo:add` は未登録タグを拒否し、`photo:search` は別名を正規タグに変換して検索します。`npm run validate` は photos.yaml に辞書未登録タグが残っていないか検査します。

```bash
npm run photo:add -- --file <画像> --id class-group-01 --rights "掲載同意の根拠と使用条件" --caption "教室で課題に取り組む学生" --tags classroom,lesson,student
```

現在の正規タグ:

- `outing` 屋外・校外
- `food` 食事・料理
- `group` 集合・複数人
- `ceremony` 式典・行事
- `staff` 教職員
- `portrait` 人物ポートレート
- `classroom` 教室
- `lesson` 授業・学習
- `student` 在校生・学生
- `event` イベント
- `street` 街・通学路
- `other` その他

タグは小文字の英語または数字をハイフンでつなぎます。意味が近い言葉を増やす前に既存タグを検索し、表記を揃えます。人物の所属や活動を写真から確認できない場合は推測でタグにしません。`consultation` は実際の相談場面が写る写真だけに付けます。

既存79枚のタグはこの辞書に収まっているため、今回の仕組み化で既存ラベルの一括推測・変更は不要でした。新規登録時は写真を見て正規タグを付け、既存写真のタグ不足を見つけた場合は写真の実体を確認してから更新します。
