# B案：現行写真の構図を残す・自然な人物調整 r01

A案（JP4-R01）は新しい4人を固定して3シーンを生成。B案は現行パンフの各写真を参照し、人物の位置・服装・ポーズ・場面を保ち、肌の褐色感と顔立ちの多様さを残しながら控えめに調整する。

| ID | 元の紙面 | 場面 |
| --- | --- | --- |
| B-PHOTO-R01-S01 | 医専パンフ・PDF2ページ | 4人組 |
| B-PHOTO-R01-S02 | 医専パンフ・PDF8ページ | 教員と学生のPC授業 |
| B-PHOTO-R01-S03 | 医専パンフ・PDF11ページ | 保護者との相談 |

元の紙面にある文字・色帯・情報パネルは除き、画像部品のみ生成する。正確な文章は紙面側で保持する。ページ番号はPDFの通し番号であり、元紙面に刷られた番号とは区別する。

「日本人・アジア系・日系人の境界を感じる」という依頼は画像の表現指定であり、元写真の実在人物の国籍・ルーツを判定したものではない。Bも生成編集したイメージとして扱い、在校生の実写記録にはしない。現行PDF未変更・採否未確認。

元は名前整理前から保存されている掲載版。宣言の改名後に再描画していないため、元PDFは `asset:get --saved` で実体同定して参照。`reference-inputs/source.json` に元アセットSHAと切り出し座標を記録する。
