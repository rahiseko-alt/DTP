# 加工版使用の確定

人間の最新指定:「補修しないまま使えるでしょ？加工版として」

写真単体45点、文字/帯/ロゴ一体の加工版12点、計57点を使用可能な素材として整理。後付け要素を含む画像は `ready_composite` とする。以前の `restoration_required` は今回の人間指定により解除。写真内の文字/ロゴは一体なので、写真と文字の個別編集は前提にしない。

個別PNGの画素は変更せず、元画素一致57/57を再検証。一覧・各manifest・各README・引継ぎを更新。生成候補を採用せず、補修/再生成なし。

過去の独立レビューの補修未完了表示は当時の状態分類として残す。素材の現在状態は更新済みmanifestとこの記録を参照。

冊子組込み・原画全体の組み直し・mainマージの承認はこの指定から推定しない。
