# GPT原画忠実パーツ

人間が提示した7枚のGPT生成原画を正本とし、近い再現度と勝手な変更禁止の指示を優先して制作。

## 原画保持版

`index.html` に全57点と原画上の切り出し位置を表示。PNGは元画素の矩形抽出で、顔・表情・服・人数・姿勢・背景・色を変更していません。`pixel-verification.json` は57/57点の復号画素一致を記録。原本7枚もDownloadsの添付とファイルSHA256一致を確認。

- 写真単体の45点は原画保持パーツとして使用可能。
- 大写真6点の紙面文字/バッジと、講師ページ6点の白円ロゴは後付け編集要素が写真に重なっているため、分離は未完成。
- 写真内の服の文字・モニターUI・ポスターやSNS作品の文字は被写体の一部として残す。画面内の文字を無断で消さない。
- 表紙は矩形の群像写真。下部コピーと干渉する靴・裾の全体は含まれず、透過人物全身パーツではない。
- 冊子モックアップの湾曲/遠近は補正せず元画素を保持。推定配置寸法は写真の縦横比を維持する。実寸・印刷品質の合格値ではない。

## 補修検証

ImageGenによる大写真6点の文字除去候補は人物の細部が変わるため、全画像の置換を不採用。文字画素の限定合成4点も継ぎ目/文字残り/衣服の断片変化が残るため、不採用。候補画像は完成一覧・原画一致57点に含めません。

原画で文字や帯に隠れた写真情報は復元不能。局所的な推定補修を許容するか、文字/帯を残した原画保持を優先するか、人間に確認中。回答前に推定復元を完成素材として採用しません。

学校の事実・既存BOOK・既存素材は変更していません。AI生成の人物を実在在校生の実写真として登録していません。
