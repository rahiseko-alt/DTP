# パーツ制作

Codexでは `dtp_parts_designer`、Claude Codeでは `dtp-parts-designer`へ注文を渡す。対応しないホストでは役割TOMLを読み別エージェントに依頼し、設定適用の制限を明示する。

## 注文

用途と読者、参照素材パス、配置寸法mm・比率・目標dpi、トリミング/塗り足し、文字領域、透明背景の要否、色・質感、納品先を渡す。依頼から判断可能な値は制作側が具体化し、学校事実を推測で追加しない。

## 制作と納品

- 背景・光・質感は文字なし画像、可変枠・罫線・単純形状はコード、正確な文字はページ側。
- 画像の生成・編集は利用可能な正規ツールで行い、入力した原本/参照と編集内容を記録する。
- 拡大目視、α、端切れ、余白、文字状ノイズ、配置時の実効dpiを確認する。
- 想定紙面に合成し、文字領域・可読性・実解像度を確認する。未確認は未確認として使用制限を返す。
- 共通画像はshared/generated-assets、共通コードはshared/components/*.hbs・shared/layouts/*.css、BOOK固有は対象BOOK。既存IDを上書きせず更新版を作る。
- 素材実体、同名.prompt.yaml、px/mm/dpi・α・配置上限・目視/合成結果を返す。
- 学校事実・冊子全体・台帳は変更しない。冊子への組込みと承認は編集制作・独立レビュアー・編集長に返す。

仕様はsystem/rules/image-generation.md、page-layers.md、output.mdを参照する。
